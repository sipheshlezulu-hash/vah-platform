# VAH Afrika Store

Premium digital storefront for VAH Afrika.

## Direction

**CREATION IS SACRED.**

The store is designed as the first commercial expression of VAH Afrika: a premium African creator movement that happens to have a commerce engine.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Shopify Storefront API (integration-ready)

## Planned experience

Home · Shop · Digital · Story · Fuel the Movement · Homecoming

## First Drop

- Creation Is Sacred
- Build In Silence
- Become The Tree
- Let The Fruit Speak
- VAH Afrika — Create. Build. Become.

## Development

The storefront is intentionally integration-ready. Product, cart, checkout, inventory and customer data should come from Shopify rather than being hard-coded.
